# 不周山原生子 Agent 协作

桌面不周山提供「子 Agent」入口。用户继续在主会话提出目标，主 Agent 根据工作需要调用原生分工工具，自己编写子任务、追加说明、接收结果并汇总；简单任务不强制分工。其他主题与移动端不增加该入口或协作指示。

## 原生能力与边界

核验版本：Codex 0.162.1、Claude Agent SDK 0.3.285。Codex 使用原生多 Agent 工具及父子线程关系，Claude 使用内置 Agent 工具、原生任务事件及 SDK 子 Agent 历史读取接口。面板不建立第二套任务队列、不为显示子任务恢复或接管子线程，不会因轮询、刷新或重连重复派发任务。子任务权限遵循主会话原有模式。

不周山发送普通会话消息时携带 `nativeCollaboration: true`，Codex 通过原生每轮 additionalContext、Claude 通过本次 SDK query 的 systemPrompt.append 接收按需分工指示，用户消息正文不拼入这些指示。主机全局设置与语音总控专用配置保持原值。其他主题的新轮次会清空应用附加上下文，不再新增该指示；已有原生对话历史不会被删除。

这是同一提供方的原生协作：Codex 分给 Codex 子 Agent，Claude 分给 Claude 子 Agent。本次不引入跨提供方、跨主机调度。正在运行的旧轮次不会被替换；协作指示从后续消息开始生效。

## 界面与读取

工具栏入口显示真实子任务数量和运行状态，默认收起，不自动挤压会话。展开后查看任务、状态与对话。子任务可以在主任务运行过程中新增，无须预先选择已接管的独立会话。没有子任务时，说明直接在主会话提出目标、由主 Agent 按需分工。

只读接口 `POST /api/sessions/:id/subagents` 复用用户登录、CSRF、项目内容同步授权，以及主机、原生线程、执行段和连接代次校验。请求经过临时中继，不存入 commands 队列。返回前再次检查访问权限，拒绝跨父会话读取。分页限制响应大小；长回复分段读取。普通连接同步不会被误判为更换主机，真正断线与版本变化则丢弃旧回复。面板切换会话时取消旧请求，不串入其他会话的子任务。

Codex 按原生 parentThreadId 查询子线程。Claude 子任务事件与主会话流分开处理，子任务结果不终止父任务。主机重启后若历史只能证明任务存在、不能证明当前状态，显示待确认，不伪造完成。用户原生历史仍在主机，面板不复制持久保存子 Agent 正文。

## 移除自建浏览器和手工分工表

Codex 原生有桌面内置浏览器和扩展能力，但本次接入的独立 App Server 协议没有可供 AgentFleets Web 直接显示、控制的标签页/截图接口。Claude 的 Chrome 扩展同样不是嵌入本面板的画面接口。因此移除面板自建截图浏览器、私有 MCP 注入、控制接口及 Playwright 打包依赖；不修改用户已有原生浏览器扩展或其他 MCP 配置。

手工填写任务、选择独立会话、手动汇总的旧分工入口及后台派发服务同时退役。数据库中旧 collaboration_plans 表保留历史，不删除记录、不自动继续或重派旧任务；已经提交的原生任务由其原会话继续管理。

## 生效与发布

主机需 AgentFleets 连接服务 0.30.97。旧连接服务的面板入口会提示更新，不能把前端更新当作主机运行版本已更新。面板使用语音安全发布器，活动通话自然结束后才切换；不强制刷新、重启主机或打断任务。已打开页面在通话结束后重新加载，新版主机服务按现有空闲升级流程生效。

验证包括提供方协议适配、父子边界、长回复分页、子任务事件不污染父任务、过期读取丢弃、内容权限撤销、主题隔离及桌面界面。隔离测试与真实用户会话区分，不用合成回执声称已完成真实云端多 Agent 任务。

## 本轮验证记录

- Web 全量 593 条通过；最终状态文案补充后的 10 条子 Agent 回归和生产构建通过。
- 控制面板 247 条通过；Agent 351 条通过，8 条需要显式原生环境开关的测试跳过。
- 独立 Codex 0.162.1 observer 对已有项目只读实测：找到 15 个直接子 Agent，读取到原生终态、回复及分页；执行请求为 0，未接管任何会话。
- Claude SDK 参数、真实事件结构、子任务 ID 映射和生命周期用协议/本机源码与模拟流验证；未启动真实 Claude 模型分工，不声称该部分完成了云端端到端实测。
- Chrome 检查 1440、1120 视口及 860 宽内容区，无横向溢出；其他主题、390px 手机无新入口。截图使用隔离模拟数据。
- 附带的旧浏览器会话只有部分消息且不含执行记录，无法据其确认当时实际操作了哪个浏览器；能力判断依据当前原生协议、安装源码及官方说明。

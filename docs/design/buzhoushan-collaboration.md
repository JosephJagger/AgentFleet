# 不周山协作工作区（第一、二阶段）

仅桌面不周山提供入口；不改变其他主题的聊天、心跳和会话选择。

## 浏览器协作
所选主机启动隔离的 Chromium 上下文，通过现有认证中继传递页面截图和输入，禁止用第三方网页 iframe 冒充共用浏览器。页面明确标记浏览器位置和人机控制权。默认人工控制；交给 AI 后，AI 的网页修改操作逐项请求面板确认。人工接手撤销尚未执行的请求。截图与登录状态不入会话数据库。断线暂停自动操作，闲置关闭，关闭后不恢复旧操作。需要主机安装 Chromium/Chrome，新 Agent 不自动下载或打开用户浏览器配置。

## 分工处理
当前会话作为总负责人，用户填写或粘贴分工，选择已接管的 Codex/Claude 会话，确认后执行。最多六项，依赖只指向前面的任务，避免循环。已有项目写入互斥继续生效。同项目排队，不使用并行写入绕过原生权限。进度关联 commandId/nativeTurnId，不把会话其他轮次当成任务结果。原始结果由用户查看，显式汇总回主会话。用户可以暂停后续派发、停止确切任务；未知结果不自动重试。登录失效及服务重启暂停后续派发，重新确认后继续。

## UI
沿用不周山 #1e1e1e 背景、#252526 面板、#3c3c3c 分隔、#3794ff 操作色、#89d185 成功色。文字沿用现有字体与输入框字号，工具标签 13px，正文 14px，数据等宽。会话工具栏增加“浏览器”“分工”两个入口，展开右侧工作区；工作区可关闭但不自动取消任务。浏览器显示位置、地址、控制权和待确认动作，分工卡片显示真实状态、主机、模型来源、依赖与结果入口。避免新增装饰动画。

## 验证与交付
使用隔离目录、合成网页与虚拟执行回执验证，不访问真实用户账号或派发生产任务。覆盖跨用户隔离、重复请求、人工接手竞争、失联、依赖失败、未知结果、刷新恢复和其他主题入口隔离。主机代码需新版本；面板发布使用语音安全发布流程，不能强制重启。

## 第一版使用方式与边界

- 会话工具栏点击“浏览器”。显示的是所选主机上的独立浏览器，不是打开面板那台电脑的现有 Chrome，也不继承个人登录。先打开页面、手动登录，再点“交给 AI”，下一轮普通会话可调用浏览器工具。每项 AI 操作都有“允许这一步 / 拒绝”。同会话通话期间不能替换其执行连接。
- 点击“分工”，填写目标后可让当前助手用计划模式拟定草稿，也可直接填写任务；选择已经接管的 Codex / Claude Code 会话并设置依赖。AI 草稿必须点击审阅、确认才会启动执行任务。当前版本不自动创建助手会话、不生成 worktree、不跨主机复制项目文件。
- 同项目任务仍串行，不影响原有写入保护；不同项目可独立执行。暂停/取消后续派发不会终止已运行的任务，停止按钮只针对该任务确切的原生轮次。未知回执需查看原会话，不自动重发。助手结果最多传递 12000 字，结果内容被删除、过期或禁止同步时，依赖任务阻塞并说明原因。
- 第一版浏览器采用每两秒截图预览，支持点击、输入、按键、滚动；不是视频串流。弹出窗口、下载和文件上传暂不支持。验证码和复杂拖拽可能需要后续能力。
- 浏览器需要 **0.30.94 便携版连接服务**与 Chrome / Edge / Chromium。现有单文件 SEA 安装不包含浏览器模块，界面会明确说明，不会降级到无沙箱。Linux 需要能启动 Chromium 沙箱的普通用户环境。Windows / macOS 打包包含 Playwright 依赖，但本轮没有在实体 Windows / macOS 上实测。
- 页面预览停止超过 30 秒，AI 不能开始新网页动作；空闲 10 分钟关闭浏览器并丢弃登录状态。主机断线撤销待确认动作并切回人工控制。浏览器系统进程仍有短期内存/临时配置目录，正常关闭清理；截图及登录信息不会存入面板会话数据库。
- 分工任务的用户指令和命令标识持久化；助手结果从原会话按权限与有效期读取，不另存结果正文。服务重启或创建者登录失效暂停后续派发，用户可以检查后继续。
- 第三阶段（SDK / 事件触发）与其他主题入口不在本次范围。

## 发布说明

本次源码与测试产物没有部署到生产，没有升级任何现有主机。体验需要面板新构建；浏览器还需要对应主机新版便携 Agent。发布前仍须按 `CONTRIBUTING.md` 使用安全发布器，等待语音自然结束，不能强制重启在用服务。数据库版本 55 新增分工任务表，旧面板版本会拒绝该数据库，回滚应使用发布前备份，不能直接强行降版本。

## 本轮验证结果

- 全量控制面板测试：242 通过。
- 全量前端测试：567 通过。并行构建期间一条原有中文输入建议测试超过默认等待时间；停止重负载后完整重跑通过，未改动该测试或输入逻辑。
- 全量 Agent 测试：348 通过，10 项需显式环境开关的原生集成测试默认跳过。
- 本功能专项实测：32 通过，包含主动开启的真实 Chromium 合成网页操作、无登录独立 Codex 进程的 MCP 工具发现，以及 Claude SDK 参数、接管竞争、失联与重复操作验证；未向真实模型提交任务。
- 类型检查、前端生产构建、Linux 便携包与 SEA 单文件包构建/启动校验通过。产物仅位于临时测试目录，未替换发布目录。
- 用隔离演示页面检查 1440 / 1120 桌面视口，以及 760px 会话区域的上下布局。演示截图不代表生产任务或线上发布。

# Codex 协作模式

面板新任务默认使用普通执行（`default`）。继承顺序是统一设置 → 主机 → 项目 → 会话；模型、推理强度和模式独立继承。旧整组配置中遗漏的模式，以及旧的“使用原生值”模式选项，现在都恢复为继承，不会让原生线程遗留的 Plan 状态决定新任务。

设置里明确保存的 Plan 会持续生效，直到修改或恢复继承。输入框旁可直接选择普通执行、规划模式或恢复继承，保存只改变模式。正在执行的任务及已经提交/排队的任务不变；单次 `/plan` 等临时覆盖仍只作用于对应提交。

每次新建或排队任务时，控制面冻结生效模式。已知模型时通过 `settings.mode` 一起下发；首次使用原生模型而模型尚未上报时，连接服务在创建/恢复线程之后，从实际原生响应取得模型，再构建 `collaborationMode`，不猜测目录中的模型。后者需要连接服务 0.30.77。主机无法取得模型或不支持模式时会报告错误，不声称切换成功。

当前任务的模式仅显示绑定该 turn 的接受记录。原生接管没有可靠模式信息时显示“模式未确认”；这与下一轮待生效的模式分开显示。

排查时核对 `turn.started.settings.mode`、对应 turn 的 `acceptedSettings.mode` 和配置来源。更换模型本身不代表模式已切换。

# Agent 0.30.155 — Grok interview and plan-exit fixes

This release follows [the 2026-10-27 Grok ACP audit](../providers/grok-acp-20261027.md). It requires this panel build and Agent 0.30.155.

- Native interviews treat an omitted or JSON `null` multi-select flag as single-select, and accept real multi-select answers.
- Permission changes stay in the same Grok process unless the choice enters or leaves always-approve.
- A successful session fork requests a catalog scan. Workflow rows can fill the composer without sending.
- Approving or abandoning a plan stores the next request as explicit default. A later save receipt cannot restore the old plan mode, and a snapshot from before that session update is not sent.

Plan mode is not an OS sandbox. Hosts adopt 0.30.155 through the existing safe update flow. Publication must not restart active tasks, voice calls, or SSH streams.

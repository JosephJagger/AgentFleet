# 未提交改动进入待处理列表（0.30.146，待发布）

开发会话结束后，目录仍有未提交改动时，在现有「待处理」列表增加一张「未提交改动」卡片，和权限确认、问题使用同一个入口及导航计数。点击卡片只打开对应会话，不会提交代码、批准工具操作或派发任务。

主机连接服务后台只读检测 Git 状态，包含已暂存、未暂存和未跟踪的非忽略文件；通过心跳上报目录、仓库根目录、是否有改动、检测时间，不上传文件内容。读取有超时、并发限制和缓存，不阻塞心跳；Git 读取失败或非 Git 目录作为未知处理。

控制面按主机和实际工作目录去重，选择最近完成的会话作为处理入口。主目录和独立工作树分别提醒，同目录不同 Agent 不重复提醒；有运行中、等待确认或状态未知的会话时暂缓。新建但未执行的空闲会话、已归档/删除会话不产生提醒。提醒说明的是目录状态，不能证明改动由某个会话独自完成。

提交后在下一次成功状态同步后自动移除。常规检测间隔 30 秒，随后随 15 秒心跳同步；大量目录会分批轮转。主机离线、缺少检测能力或检测结果超过 120 秒时不生成新的未提交提醒；列表为空不代表这些未知目录已全部提交。

上线需要同时发布面板和 Agent 0.30.146；仅更新网页、旧版主机仍在线时不会获得 Git 检测结果。该版本没有新增数据库迁移。按 `AGENTS.md` 和 `docs/release-provenance.md` 从干净 main 准备正式发布，不能用仅网页镜像发布此版本。

验证涵盖真实临时 Git 仓库和工作树的暂存/未暂存/未跟踪/提交清理、后台心跳采集、目录去重与 Agent 混用、工作区隔离、离线/过期/归档排除、元数据过滤，以及待处理混合计数和会话跳转。测试不访问真实会话或修改生产目录。

# Claude 额度读取失败时保留已核验快照（0.30.148）

此前 Claude 元数据查询失败会清空已有额度，控制面随后返回空账号列表，主机卡片退回总 token 消耗。这个路径没有按任务是否运行来隐藏额度；截图发生时的具体请求失败原因没有历史证据。

本版本把模型、额度和账号查询分别限时处理。额度请求失败、超时或返回缺失窗口时，只有当前原生账号信息确认与上次成功读取的邮箱、组织、认证来源及订阅一致，才保留最后成功的额度及其原始更新时间，并标记更新失败。账号比较值仅在 Agent 进程内存中使用，不随发现信息上传、不用于跨主机合并。账号变化、明确不支持额度、无法核实账号或运行时路径变化时不沿用旧值；重启后重新读取。

控制面保留失败标记并将该快照标为过期。主机卡片及用量详情显示“额度更新失败，显示上次数据”，恢复后清除提示。网页接口暂时失败也保留已显示的额度卡片；成功收到空账号列表时清除旧卡片，切换主机或智能体时不继承旧数据。

验证覆盖：原生控制请求超时、同账号缓存、账号/组织/认证变更、初始化失败、恢复及时间戳不刷新、发现数据字段白名单、跨主机隔离、页面读取失败与恢复。使用模拟原生查询及临时数据库，不执行真实对话。发布需要完整构建；主机端修复须升级到 0.30.148 后生效，安装包发布与主机实际升级分别核验。

# Agent 0.30.124 — native append and session filtering

- Claude Code and Grok Build can accept additional input in an active managed
  turn when the updated host explicitly advertises native support. Next-turn
  queueing remains separate. Codex steering is unchanged.
- Claude tracks all accepted input UUIDs before completing the Fleet turn.
  Grok uses its native interjection extension without cancel/restart. Exact-turn,
  ownership, command idempotency and authorization checks remain in place.
- The Agent selector above a conversation only filters “切换会话”. It no longer
  leaves the open conversation, discards its composer state or resets history
  scrolling. Selecting an actual session still navigates.

See [native input evidence and limits](../native-turn-input.md) and
[session navigation](../host-session-navigation.md).

Validation before publication: 343 targeted tests passed across web workspace,
provider UI/catalog, host runtimes/resilience and control-plane/voice paths;
three builds and type checks passed. Chromium 390×844 verified filtering and both
append buttons against isolated API fixtures. Real isolated native checks used
Claude 2.1.296 with SDK 0.3.285 and Grok 1.0.62, including a Grok image interjection.

Deployment uses the guarded publisher, preserving immutable previous downloads.
The browser change applies on the next page load. Native append requires a safe
host-service update to 0.30.124; no active host task or voice call is force-restarted.
The npm installer wrapper and native CLI versions are unchanged.

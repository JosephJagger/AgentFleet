# Agent 0.30.151: managed Claude permission discovery

Managed Claude installations now report permission modes from the verified executable actually selected by the runtime manager. Previously only the host PATH detector probed `--help`; managed mode omitted this metadata, leaving session permission controls disabled even on current Claude versions.

Both detection paths share the same bounded, read-only help probe and allowlist. Missing or failed probes report no capabilities. The managed binary's size and checksum are verified before execution. This change does not select a permission mode, change existing session settings, or grant tool approval.

Install Agent 0.30.151 on affected hosts and wait for the next discovery heartbeat. Active tasks and calls must finish before the standard updater restarts the host Agent. Web publication alone does not update host capabilities.

Validation: permission discovery fixtures cover default/manual names, supported-mode filtering, missing metadata and probe failures. Runtime-manager regressions cover host/auto/pinned modes, the selected binary path, and rejection of a tampered managed executable. Existing Claude runtime tests cover permission dispatch and plan transitions.

# 未提交改动支持「忽略本次」（0.30.147，待发布）

待处理中的未提交改动卡片新增「忽略本次」。点击后隐藏当前这批改动并更新导航计数；仍可通过卡片进入会话。忽略记录按账号、工作区、主机和工作目录保存在服务端，刷新页面、换设备、同目录切换会话不会重复提醒，也不会影响其他账号的提醒。

Agent 上报当前改动的摘要：Git 状态、索引对象 ID、HEAD 和改动文件的大小、修改/状态变化时间、模式。不会读取或上传文件内容；检测同一文件再次修改、嵌套未跟踪文件变化、暂存区变化和删除/重命名。只改变时间戳也可能重新提醒，避免漏报。检测按实际工作树根目录进行，子目录会话使用相同摘要。

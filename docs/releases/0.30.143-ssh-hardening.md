# SSH 互通加固（0.30.143，未发布）

修复 `docs/reviews/2026-10-21-main-72h.md` 中 SSH 互通的三个问题：

- **F7 口令泄露到命令行。** 解锁加密私钥时不再使用 `ssh-keygen -p -P <口令>`，改为 `SSH_ASKPASS` 辅助脚本 + 子进程环境变量。辅助脚本固定、不含口令；`ps` 看不到口令。错误口令以「私钥仍未解锁」为准判定（askpass 模式下 `ssh-keygen` 可能返回 0）。
- **F8 提示词误导。** 主机摘要记录指纹是否已固定；Agent 提示词与 `HOSTS.md` 如实标注，旧版 `state.json` 无该字段时不作任何断言。
- **verify / test 越权。** 两个接口补 `requirePlatformAdmin` 并限流，鉴权先于账号查询。

测试：本地代理 `ssh-access` 7 项（新增口令不入 argv、错误口令、指纹状态如实）；控制面新增 `ssh-routes`（普通用户 403、管理员放行、限流 429），已验证撤销修复后该测试失败。

后续阶段：路由策略与 macOS（阶段 1）、面板 SSH 字节流中转（阶段 2）。

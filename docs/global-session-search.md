# 全局会话搜索

入口是页面顶部的「搜索」或主机详情顶部（「收起列表」左侧）的「跨主机搜索会话与正文」，快捷键为 Ctrl / ⌘ + K。输入为空时列出最近活跃的会话；选择结果会打开对应主机、项目和智能体的原会话，不接管或发送任务。

## 匹配范围

- 默认覆盖当前用户工作区中的全部有效主机，包括离线主机的已同步记录；可按主机、智能体和「仅已接管」筛选。
- 匹配标题、项目名称、目录、主机名称和智能体标识。标题还支持邻近字符省略及英文单词单字符拼写误差。
- 两个字符起搜索已同步的用户提问和智能体回复。多个关键词用空格分隔，可同时匹配一条消息及其主机、项目、标题等资料。
- 结果显示来源和命中片段；标题精确匹配优先，其次为标题包含、项目资料、正文和相近标题，同级按最近活动排序。结果分页返回，不受仪表盘当前加载的会话数量限制。
- 本版为关键词与标题模糊匹配，**没有语义向量检索**，也不向外部模型发送搜索词或历史内容。

「已接管」不是正文可搜索的充分条件：还需要已同步且在保存期限内的提问或回复。未接管但已同步过正文的会话也可匹配。未同步、关闭正文同步、过期、删除和旧内容版本不会进入正文结果。原生宿主机上尚未同步的历史不会因为搜索自动读取或接管。

## 实现与边界

`GET /api/session-search` 是鉴权后的只读接口，支持 `q`、`machineId`、`provider`、`managed=true`、`offset`、`limit`。响应禁止缓存。查询限制为 160 字、8 个关键词，每页最多 40 条；页面默认 20 条。

直接读取现有事件与正文，未新增正文副本或数据库迁移。只读取 `item.completed` 中的 `userMessage` / `agentMessage`；工具日志、命令、推理内容及附件地址不参与正文匹配。返回前重新核对具体事件的删除、保留期限、内容版本及工作区可见性，HTTP 层重新验证登录状态。

生产 PostgreSQL 使用单独的异步只读连接池（最多 2 个连接、单条查询 4 秒上限），不占用主连接处理心跳或命令。先筛选候选 JSON，再提取正文和核对最新消息版本，避免对每条事件重复解析或嵌套扫描整个会话。旧输出中的 JSON 空字符只在搜索读取时替换为显示占位符，原始记录保持原样。

浏览器输入防抖、取消旧请求并拒绝过期响应；服务器停止已断开请求的后续查询。查询超时或正文读取失败时，页面明确提示当前只有标题与项目结果，并提供重试。

## 验证

后端用例覆盖跨主机、跨智能体、离线记录、模糊标题、多文本块、长回复尾部、分页、文字与附件区分、过期/删除/内容版本/工作区隔离、异步删除复核、取消搜索和登录撤销。相同服务用例在 SQLite 和独立 PostgreSQL 测试 schema 上运行。

前端用例覆盖准确打开结果、键盘操作、中文输入法、取消旧搜索、分页筛选、英文界面、纯文本高亮和 HTML 转义。浏览器使用独立的内存数据预览，验证手机/桌面布局和跨主机会话导航。

# 统一语音音色

在设置 → Codex 配置 → 统一默认 → 语音音色中选择并保存。会话通话与面板总控共用工作区设置，默认 Sol。只影响下次通话；不会重新连接当前通话或改变任务模型。

选项根据托管 Codex 0.159.2 的 ThreadRealtimeStartParams.RealtimeVoice Schema 核实，共 19 种。服务端在每次拨号时读取已保存配置，通过 voice.control 传给连接服务，最终作为 thread/realtime/start.voice 传入原生接口。没有模拟语音或自动回退音色。

非 Sol 音色要求连接服务 0.30.73 或以上；旧主机会明确拒绝并提示更新。原生服务仍可因账号权限或服务不可用拒绝通话；Schema 支持不代表逐个音色已在每个账号上试听验证。

数据库迁移 47 新增 voice_preferences，仅存工作区音色、修订号和更新时间。与任务运行配置独立，保存使用修订号防止覆盖其他浏览器的修改。切换音色无需复制主机账号或改动主机的 Codex 配置文件。

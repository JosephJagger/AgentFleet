# Codex 0.160.1 Web 能力补齐

基线：Codex 0.160.1，2026-10-07。按用户场景分配入口；接口数量不等于产品完成度。本文件区分已实现、方案替代和未接入功能。

## 已实现的入口

| 入口 | 能力 |
| --- | --- |
| 设置 → Codex → 统一默认 | 推理摘要、子代理协作方式、停用插件；按全局、主机、项目、会话逐项继承，支持恢复继承 |
| 设置 → Codex → 原生配置 | 读取配置值与来源；使用原生配置版本保护保存；回复详细程度、摘要和原生功能开关 |
| 主机 → 账号与工具 | 账号与额度、插件与连接、运行环境、实验功能分区；无需借用某个会话管理账号 |
| 主机 → 账号与额度 | 现有登录/额度功能；Gateway 状态；使用已存在的 AWS profile 设置 Bedrock，不接受密钥 |
| 主机 → 插件与连接 | 原有插件/MCP 操作；额外技能目录持久化与新进程恢复 |
| 主机 → 运行环境 | 原生远程控制状态；导入配置和历史的预览、勾选、再次核对及结果记录；Windows 沙箱检查与安装入口 |
| 主机 → 实验功能 | 插件搜索、原生音色目录查看，以及已有实验操作 |
| 工作 → 项目会话 → 项目工作区 | 文件、交互命令、历史、集成，独立于会话配置 |
| 会话待执行队列 | 排序与正文编辑；仅限等待中的条目；保持附件、位置和到期时间，保存时重新校验执行配置 |
| 管理 | 保留现有托管版本验证、升级策略和系统信息入口；不把普通用户任务搬到管理员页面 |

会话配置保留本会话覆盖、执行权限、结构化输出与原生会话操作。主机登录和插件管理不再集中在会话配置。

## 方案选择和边界

- **文件管理采用面板实现**：只在已注册项目范围内处理普通 UTF-8 文本（48 KB）；支持创建、目录、复制、保存备份、删除到回收站、恢复到新路径。拒绝链接、敏感配置和越界路径；保存前检查版本。大文件/二进制继续下载，不能在此编辑或删除。回收站展示最近 50 份，不自动永久删除。
- **交互命令采用原生 PTY**：命令、输入、输出、宽度调整、中止及退出码；绑定项目和执行段。最长 120 秒、输出上限 36 KB。运行时阻止连接服务自动重启；断线不重发。不是无限期驻留的远程桌面终端。
- **历史采用新分支替代原地回退**：选中任务之前创建新分支，保留原会话。不会回滚磁盘。未调用 `thread/revert`，避免历史投影、附件引用和内容 epoch 不一致。
- **面板队列作为唯一调度入口**：编辑会原子创建替代命令并取消旧条目，原命令内容及哈希保持不可变；版本冲突/已派发均拒绝。未导入原生队列，也不另开原生队列写入入口，避免双重调度。
- **子代理查看，不夺取控制**：原生父子关系过滤，显示直接子代理和分页回复；读取内容前再次检查父会话和目录。不会把普通会话误判为子代理，也不直接接管父任务正在管理的子代理。
- **原生功能开关**：仅允许原生目录中 `beta`/`stable` 项目，保存时再次读取目录和配置版本；开发中、已移除、已废弃项目不开放写入。保存后新连接生效，不重启当前任务。
- **原生导入**：由主机原生检测用户目录，历史最多 25 个会话、最近 30 天；预览最多 40 个分类项。浏览器只提交已选指纹，主机重新检测并匹配，不接受浏览器拼接的任意迁移路径。启动回执不等于导入成功，另读原生导入记录确认。
- **额外技能目录**：原生接口只管理当前进程，AgentFleets 额外持久化、版本核对并在新进程恢复。

## 尚未接入 / 不宣称可用

- **动态 v3 音色和语音模型切换**：0.160.1 `thread/realtime/listVoices` 只返回 v1/v2 目录；保留已有经过验证的 v3 音色设置，不把它们混用。
- **插件远程分享/权限目标编辑**：没有进行真实账号下的发布、撤销或分享目标验证；现有 GitHub 插件市场功能保留，不声称等同原生远程分享。
- **MCP 事件流**：尚无已验证的流服务及生命周期测试；现有工具调用、资源读取和授权继续可用。
- **设备证明/验证**：没有伪造浏览器设备证明或宣称提供原生客户端等价能力。
- **原生远程执行环境注册**：现有 AgentFleets 主机注册、项目隔离与调度继续作为方案；未开放另一套携带 bearer token 的执行环境注册入口。
- **Windows 沙箱安装、Bedrock 切换和真实数据导入**：入口与参数/权限/回执链路已实现；本次没有在真实主机执行这些变更，因此不能称为跨平台实测通过。
